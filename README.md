# Bhagwati Printers Quotation Generator

A minimal, dependency-free web application for generating quotations for Bhagwati Printers.

## About

- Plain HTML, CSS, and vanilla JavaScript.
- No frameworks, no package manager, no build system, no backend, no database.
- Designed for deployment on GitHub Pages.

## Run locally

Open `index.html` in any web browser. No server or installation is required.

## Project structure

```
├── index.html   # entry page
├── style.css    # styles
├── app.js       # application logic
└── assets/      # static assets (images, etc.)
```
